# Sistema de Gestão de Restaurantes

Sistema em Python para gestão completa de restaurantes, incluindo clientes, menus, pedidos e análise de dados com visualização gráfica e geográfica.

---

## Funcionalidades

### Restaurantes
- Registo completo de restaurantes
- Validação de dados
- Cálculo automático de rating

### Rating
rating = (avaliacao * 10) / preco

### Histórico
- Registo de alterações
- Gráficos de evolução

### Clientes
- Registo com ID único

### Menus
- Criação e gestão de itens

### Pedidos
- Registo completo de pedidos

### Mapa
- Visualização com Folium
